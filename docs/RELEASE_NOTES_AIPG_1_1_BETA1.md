# AIPG 1.1.0-beta.1 Release Notes

Released on 2026-07-31 after formal adoption, repository publication, and
successful CI.

## Framework identity

The domain-neutral framework is now AIPG: AI Production & Governance
Framework. GUIF remains the visual-production domain and compatibility API.

## New workflow

`master-guided-layer-creation` treats the master effect image as style and
layout guidance. It analyzes coarse layers, applies adaptive creative freedom,
creates from bottom to top, recomposes after each layer, scopes revisions, and
exports a manifest.

## Compatibility

The `guif` import, command, Skill, prior workflow schemas, private storage
variables, and existing records remain supported.

## Evidence boundary

All public tests use fictional data. Real user Themes, images, conversation
records, credentials, private paths, and candidate evidence remain outside Git.
